# 🌤️ Weather Application

A simple and intuitive **Weather Application** built using **C# (.NET Framework)** with a **WinForms** graphical user interface. This application fetches real-time weather data using the [wttr.in](https://wttr.in) API.

---

## 🛠️ Features

- **Real-Time Weather Updates**: Displays current weather conditions for any location.
- **User-Friendly Interface**: Built with a clean and responsive WinForms UI.
- **Search Functionality**: Allows users to search for weather in different cities.
- **Detailed Data**: Provides information on temperature, conditions, humidity, and more.

---

## 📚 Technology Stack

- **C# (.NET Framework)**: Backend programming and logic.
- **WinForms**: UI design for a desktop-based application.
- **[wttr.in](https://wttr.in)**: API for fetching weather data.

## 🌐 How It Works
Enter a Location:

Type the name of a city or location in the search box.
Fetch Weather:

The application sends a request to the wttr.in API to retrieve real-time weather data.
Display Results:

Weather details are displayed in the UI, including temperature, weather conditions, and additional information.
